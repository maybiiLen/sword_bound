## How Claude uses this vault
- Every change gets a section in that day's Calendar note (`Claude/Calendar/YYYY-MM-DD.md`): what changed, how it was verified, the commit hash.
- Research goes in `Claude/Atlas/Research/`, one note per research pass, with sources and UNSOURCED flags.
- Plans and checklists go in `Claude/Efforts/`. Statuses are checkboxes.
- Images go in `Attachments/` and are embedded with `![[name.jpg]]`.
- Every note has properties: type, created or date, author, tags.
- New notes link back up to this page, and to related notes with `[[ ]]`.
- Folders stay coarse (Atlas, Calendar, Efforts). New subfolders only when a pattern shows up.
- Secrets (like the Discord webhook) never go in the vault.
- In-game docs (ReplicatedStorage.Docs) are still updated for the team. This vault is the long-form record.
