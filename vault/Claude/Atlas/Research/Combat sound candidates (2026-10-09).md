Up: [[Claude]] · Used by: [[Hit feel round 3]]

Produced by a research agent on 2026-10-09 after Henry said attacks are missing key features (flinching, enemies pushed back while you push forward, super armor for bosses, sounds that feel chopped) and that the fundamentals must be done before other classes. Licensed Pro Sound Effects candidates per combat sound event, found with the Studio asset search. Reproduced as the agent returned it. Claims marked unsourced are the agent's own calls.

Source: Roblox Studio MCP `search_asset`, scope creator_store, assetType Audio, maxResults 20, audioMaxDuration 3 (a few calls used 2 or 1.5). Read only, nothing inserted.

Filter: only creatorName `ProSoundEffects` or `APMOfficial` kept. Every result below is ProSoundEffects. APMOfficial only returned music stings (e.g. "Get Up And Go - Hit", "Sneaky Schemes - Hit1"), none usable as combat SFX, so no APM rows.

Durations are the "Duration:" line from each asset description. Single vs multi notes are inferred from the description wording ("Multiple", "Various Versions", "Lots of Variations", "Back and Forth", etc.) and the length. Nothing was auditioned, so treat the notes as a starting guess and listen before wiring.

Search tool notes:
- Long queries made only of category text sometimes return a generic trending list (queries 1 and 2). Putting PSE description nouns in the query ("Flesh Slash", "Swish Med High End Sharp Swords") works much better.
- `audioMaxDuration` 1.5 returned 0 results every time. 2 and 3 work.
- `verifiedCreatorsOnly: true` did not filter out ripped uploads.
