Focus is core fighting only. Swords are the only weapon so far, and everything must carry over to other weapon classes. New attack types become fields in the weapon definition (or Combat.ClassDefaults), and the shared controller picks which one fires.

## Plan

- [x] 3. Contextual attacks: running, jump, roll attack, guard counter ([[2026-10-01]])
- [x] 4. Directional locked-on rolls ([[2026-10-01]])
- [ ] 5. Attack sounds: a whoosh per combo step, a real flesh-hit, roll and landing sounds. Started 2026-10-06, waiting on Studio being open.
